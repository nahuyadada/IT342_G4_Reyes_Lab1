# Mobile App (Android Kotlin)

This folder will contain the Android Kotlin client for the IT342 Auth Mini App.

## Required Integration
- Same backend API as web: `http://localhost:8080`
- Android emulator uses: `http://10.0.2.2:8080`
- Must support: Register, Login, Protected Profile/Dashboard, `/api/user/me`, Logout, token persistence.
